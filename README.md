## Symplectic commuting extensions

See [`symplectic-commuting-extensions.tex`](symplectic-commuting-extensions.tex) for a line-by-line LaTeX article proving:

1. Every bounded symplectic embedding on a separable strong symplectic Hilbert space (e.g. \(\ell^2(\mathbb{N};\mathbb{R}^{2d})\) with \(\Omega=\bigoplus J\)) extends to a symplectic automorphism of a larger space.
2. Commuting pairs of such embeddings admit commuting symplectic-automorphism extensions.

Compile with:
```bash
pdflatex symplectic-commuting-extensions.tex
pdflatex symplectic-commuting-extensions.tex
```
